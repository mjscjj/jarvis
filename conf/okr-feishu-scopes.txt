# OKR 模块飞书登录申请的 user scope，一行一个，`#` 起头为注释。
#
# 这些 scope 决定登录用户的 access_token 能做什么：Jarvis 用这个 token 以
# 「该用户本人」的身份读他有权限的飞书文档、知识库和多维表格，不再依赖本机
# lark-cli 里另一个人的凭证。
#
# 范围只覆盖「用户扔进来一个链接，Jarvis 替他打开」这件事所需的域：云文档、
# 云空间文件读取、知识库、多维表格。消息、日历、会议、邮件、审批、任务等域
# 不在这里——那些仍走 Jarvis 自己的身份。需要新域时在此显式添加。
#
# offline_access 换取 refresh_token，缺它 token 两小时后无法续期；
# profile:user_profile:read 用于登录后确认 token 属于谁。
#
# 只能申请 App cli_a96a0c8d82b85cb1 已开通的 scope（`lark-cli auth scopes`），
# 申请未开通的会导致授权失败。改动后所有人需要重新登录一次授权新范围。

profile:user_profile:read
