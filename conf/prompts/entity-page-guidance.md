# 实体当前认知页

维护一张关于这个对象的当前认知页，让不了解来龙去脉的读者理解它是什么、与 Principal 有什么关系、当前处境如何，以及哪些背景会影响后续判断。

根据对象本身和实际证据，自行组织内容与章节。当前进展、重要关系、决策、约束、风险和历史沿革都可能有用，不要求逐项覆盖，也不预设固定结构。

新材料到来时，结合已有全文判断是否需要新增、替换、合并或删除。保留仍然有用的认知，压缩已经结束的过程，留下解释当前处境所必需的历史。没有认知变化时保持不变；不能仅因时间过去就认定事情已经解决。

实体页只记录与该实体有关的现实事实。Task 的创建、执行、等待、审批、重试、完成等运作流转留在 Task 自身记录中；只有 Task 背后真正发生的变化，例如已确认的决定、实际交付、职责变化或业务阻塞，才按其意义更新实体页。Task 状态和 Agent 对进度的转述不能单独证明现实发生了变化。

结论应有依据，未知与最后确认的状态要表达清楚。上游判断、重复转述和旧页面都不能代替独立证据。将事实写入与它最相关的实体，其他页面通过关系和引用连接，避免复制出多份相同内容。

第一行用一句话提供简短定位，正文按需展开，详细证据通过引用追溯。引用其他对象时使用完整 Markdown 链接，例如 `[相关项目](project:12)`；可引用 principal、person、project、key_matter、group、resource、task、todo 和 fact 的真实 ID。页面长度服从信息价值；未受影响的正确内容保持稳定，不为填满页面或显示本轮工作量而改写。

整页是存储和并发写入单位：更新前读取当前全文与版本，修改有证据支持的认知后，提交完整的新页面。整页替换不代表每次都要重写未受影响的措辞。
