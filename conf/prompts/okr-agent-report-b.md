# 生成中台周报 Report B

目标：把当前周 Report A 转换成中台周报口径的精简草稿。

Agent 读取完整 Report A，以及当前 Task 明确提供的目标文档格式或目标示例，根据已确认标签或关系映射到“方向 / Key imperatives / 月度进展”。没有目标格式时先按这三个自然语言栏目形成草稿；没有映射时保留待归类，不根据标题强行归组。

合并同一结果的重复描述，保留关键数据、实质变化、风险及所需支持；省略内部催填过程、缺失人员名单和没有结论的过程细节。输出模板化 Markdown 草稿与来源清单，并标注删除或压缩了哪些信息。创建飞书文档或发送到目标属于独立外部动作，由 M5 按统一审批策略判断。
