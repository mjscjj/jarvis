# 区域对齐并形成 OKR C 建议

目标：把 Platform OKR A 与 AMS、EU、MENAT、SEA、NEA 的区域 OKR B 对齐，形成带优先级的 OKR C 候选。

读取完整 OKR 原文和稳定来源。Agent 结合业务结果、对象、范围、交付物、时间和负责人判断语义重合，不能只用标题相似度。每个匹配都列出双方证据、涉及区域和置信度，低置信度交给人工确认。

优先级口径：两个及以上区域实质重合，或有明确管理要求，建议 P0；一个区域与平台实质重合，建议 P1；其它建议 P2。该口径是建议依据，不替代资源、依赖和风险判断。输出匹配建议表、冲突/缺口、P0/P1/P2 理由和待确认项；未明确授权时不改正式 OKR。
