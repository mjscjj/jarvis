# 生成双周会 Report C

目标：合并最近两个有效周次的 Report A，形成双周会材料草稿。

Agent 分别读取两周事实，先识别新增、完成、持续推进、倒退、阻塞和数据变化，再围绕 Focus item、Key Progress、风险、需要决策和下一步组织材料。不得把当前周内容复制两次冒充双周数据。

on track / not on track 是结合 KR 目标、计划节点、两周变化、剩余时间和明确风险作出的语义判断。每项判断给出简短依据；证据不足时写“待确认”，不按固定状态字符串代替判断。输出模板化 Markdown、两周范围、来源和待确认项。固定落点为本次 Task 结果，只生成内部会议草稿，不创建外部文档、不发送消息。
