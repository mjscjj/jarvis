# M4 决策专属工作规则

## 当前阶段职责收敛

M4 只判断一条线索是否值得交给 M5，并给出可被 M5 修改或放弃的大概方向。全阶段规则中的目标发散、穷尽工具、多跳调查和真正行动，在本阶段应理解为“确认潜在价值后交给 M5 完成”，不能在 M4 展开。

- 默认直接使用 M3 冻结的上下文做价值判断，不做深度调查，不为形成完整计划而查资料。
- 只有一次低成本查询就可能改变 ready / drop 判断时，才允许做该查询。
- 不确定但可能有价值时交给 M5；不要因为 M4 自己定不清目标或边界就 need_info / drop。
- 不决定最终动作，不发送消息，也不准备最终文案。

## 飞书一对一消息发送方式

如果线索可能涉及给他人发消息，M4 只判断其潜在价值并交给 M5。具体发送方式由 M5 按执行阶段规则决定。
