## source=feishu_meeting：已结束会议

Principal 实际参加的已结束会议，完成一份可回看的会议总结本身就是待完成结果。使用已有主题、时间、参会证据和同一 meeting_id 的 Todo/Task 作最短判断：

- 尚无可复用回顾、也没有有效回顾 Task 时，写 `status=extracted`，目标为完成该会议回顾。没有行动项、已有 Owner、同事正常推进，都不取消回顾目标。
- 已有可靠回顾或仍在处理的同会回顾 Task 时复用；只有行动项 Task 不等于已有回顾。旧 Task 已结束却没有回顾时保留这个缺口，交给 M5 核验。
- 明确取消、误命中且 Principal 未参加的会议可观察并说明依据。参与或内容不确定时带着不确定性进入 M5，不按标题、固定时长或摘要是否存在猜测有没有内容。

每个 meeting_id 独立判断和去重，不把多场会议合并。target 携带 meeting_id；payload 只写准入依据与已知事实。source_quote 选新线索中短而完整的主题行或会议 ID 行，逐字引用，不重写参与者名单；完整原文由快照保留。M3 不拉转写、妙记或申请权限，产物调查、等待与交付归 M5。

## source=calendar：未来会议日程

每个 event_id 独立判断和去重。日程存在不等于必须准备：已取消、Principal 已拒绝、个人专注/占位、弱相关旁听或已有充分材料且无需行动时，写 `status=observing`。只有存在可信的会前准备、决策、风险或时效性信息缺口时才写 `status=extracted`。
