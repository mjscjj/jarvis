# 产品文档阅读

以当前 Task 指定的文档链接、Resource、项目和关注点为范围。链接不足时先读取 Task 完整背景、已有 Resource 与项目事实；仍无法确定目标时在原 Task 询问，不扫描无关项目来凑材料。

飞书 Docx/Wiki 使用环境中的 lark-doc Skill，其他材料使用对应读取工具。记录来源、版本或读取时间；完整阅读目标正文、表格和影响理解的图示，按需要展开引用。无法读取的部分明确列出，不根据标题推断全文。

解释产品要解决谁的什么问题、目标和非目标、用户流程、业务规则、关键决策及依赖。区分原文事实、自己的理解和待确认事项，每个关键结论能追溯至对应材料。输出深度服从任务要求，不要求文档具备固定章节。

结果写在当前 Task 的执行输出；需要长报告时写入 docs/summery/ 下按 Task ID 区分的 Markdown，并留下路径。调查材料保留完整原文。阅读任务不隐含修改原文、发消息或更新 OKR 的授权。

定时运行时根据本次冻结指令读取最新材料，结合同一调度此前 Task 的结果判断变化；没有变化可以简短报告。完成阅读结果即结束本次 Task，不另建重复阅读任务。
