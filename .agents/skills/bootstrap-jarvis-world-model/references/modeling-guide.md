# 世界模型建模指南

初始化的目标不是把最近 7 天的材料全部搬进 Jarvis，而是建立一张足够小、能被后续 Agent 持续修正的世界地图。先判断语义属于**实体、关系、历史事实还是未知项**，再选择现有写入入口。

## 四层模型

| 层 | 回答的问题 | 初始化时写什么 | 不写什么 |
|---|---|---|---|
| 实体 | 这个人、项目、事项、资料或群是什么 | 稳定身份、职责、目标、用途和边界 | 单次聊天、转瞬即逝的状态 |
| 关系 | 两个实体为何相关、关系在何时有效 | 现有结构化字段表达不了的重要协作或依赖 | 已由 `project_id`、`person_id` 等字段表达的重复关系 |
| 历史事实 | 某时发生了什么重要变化 | 有日期的决策、交付、阻塞、方向变化 | 静态简介、对象创建动作、无时间依据的推测 |
| 未知项 | 哪个判断还缺证据或需要本人选择 | 冲突、权限缺口、低置信候选和待确认问题 | 为了填满字段而编造的结论 |

## 实体边界

- **PrincipalProfile**：本人稳定身份、职责范围、决策边界和已明确的长期偏好。当前工作进度、一次性安排和 Agent 自己推测的偏好不进入 Profile。
- **Project**：有持续目标或稳定协作边界的工作域。记录本人角色、当前状态、优先级、仓库和关键背景；一次会议、一个群名或单份文档不是项目。
- **Person**：只收录直属上级、关键 owner、决策者和长期重要协作者。`open_id` 是业务身份，不把所有聊天对象导入；用 `relation`、`comm_style` 和 `notes` 说明其职责、与 Principal 的协作关系和已证实的沟通特点。
- **ManagedResource**：后续调查时值得反复查阅的权威文档、仓库或链接，同时写清“它是什么、何时有用”。不要把最近浏览或编辑过的全部文档都注册成资料。
- **Group**：持续产生有价值信号的监听面。`background_note` 应说明群用途、覆盖范围、关键 owner、值得关注的信号和已知噪声；只有群几乎由一个项目主导时才绑定 `project_id`。
- **KeyMatter**：不是项目、也不是可立即执行的 Task，而是需要一段时间持续看护的风险、依赖、承诺或未决问题。首轮宁缺毋滥，通常不超过 10 项。

## 关系边界

关系使用 `RelationFact`，描述要让人在脱离当前对话后仍能理解。适合初始化的例子包括：某人负责某项目的关键决策、某人是某重点事项的外部依赖方、两个项目存在稳定上下游关系。

以下关联已有结构化所有者，不再创建重复的 RelationFact：

- KeyMatter → Project：`key_matter.project_id`
- ManagedResource → Person / Project / Principal：资源自己的关联字段
- Group → Project：`group.project_id`

当前简单版本不创建 Principal 关系：PrincipalProfile 的读接口没有提供可稳定引用的数值 ID。直属上级写 Profile 的 leader 字段，同时可作为 Person 保存；不要凭空制造 principal ID。

## 基线历史事实

只有证据包含真实发生时间，且内容属于决策、交付、阻塞或方向变化时，才写 `Fact`。写入时显式传 `--occurred-at` 和 `--source initialization`。Project 和 KeyMatter 的创建入口已经记录创建事实，不要再追加“初始化创建了某对象”这类重复事实。

事实正文应包含发生了什么、造成什么影响；证据只支持“大概在某周”或只有日期没有时刻时，不要伪造精确时间或午夜时间戳，先放入未知项。

## 去重与裁剪

- Person：按同一 app 下的 `open_id` 去重。
- Group：按 `chat_id` 去重。
- ManagedResource：按规范化 URL/token 去重，同一材料只保留一个权威入口。
- Project：优先按明确 repo、项目 code 或稳定名称去重；证据不足时保留冲突供审阅。
- KeyMatter：按根本语义去重，不按不同措辞拆成多项。
- Relation：同一对实体只保留一条当前关系描述；时间边界变化时更新有效期，不复制近义关系。
- Fact：同一主体、同一发生时间和同一事件只写一次；恢复同一运行时先查询当前事实和工作稿里的读回记录。

初始化历史材料不自动生成 Task。能立即行动但不属于稳定世界模型的内容，放入 `unknowns` 或最终报告，交给用户或后续正常流水线决定。
