# 世界模型 3D 视图

> Status: proposal
> Authority: non-normative
> Last reviewed: 2026-09-11

## 目标

在现有世界模型 API 上提供空间化浏览，帮助 principal 看见当前实体、主要关系和关注焦点。它是只读视图，不改变世界模型存储。

## 数据来源

- 实体列表和 `summary`；
- 页内引用与 backlinks；
- 活跃度、状态和最近事实计数；
- 当前选中实体的一跳邻居。

不新增图数据库、关系表或 3D 专用后端。

## 第一版范围

1. 默认只加载活跃实体和有限关系；
2. 支持按类型、关键词和项目筛选；
3. 选中实体后展示一跳关系与现有详情；
4. 移动端退化为 2D 列表/关系视图；
5. 性能不满足时优先限制投影，不引入缓存服务。

## 启动条件

只有现有 2D 世界视图在真实使用中出现“关系难以理解”的稳定反馈，并能给出代表性实体规模与交互任务时再实施。视觉新颖本身不是建设理由。
