# Agent 决策与执行全景图：ImageGen 提示词

## 生成模式

- Use case: `infographic-diagram`
- Tool: built-in ImageGen
- Canvas: 16:9 landscape
- Intent: publication-ready Chinese technical architecture panorama

## 核心提示词

生成一张题为「Agent 决策与执行」的中文技术架构全景图，副标题为「从外部变化、价值准入到深度决策、执行验证与世界模型更新」。图不是简单线性流程，而要同时表达决策约束、快脑准入、慢脑决策执行闭环、结果收口和世界模型读写。

采用“三层一中心”布局：

1. 顶部为「决策约束」：Principal 目标、工作规则、审批规则、可信记忆、Tools / Skills。
2. 左侧依次为「外部变化」「Adapter 数据接入」「快脑 M3｜价值准入」。
3. 中央最大区域为「慢脑 M5｜主 Agent 决策与执行闭环」。
4. 右侧为「结果收口」。
5. 底部为横贯全图的「世界模型｜持续读取与维护」。

M3 内必须呈现四个准入问题：

- 与 Principal 相关？
- 存在未闭环结果？
- 需要 Jarvis 介入？
- 已经完成或重复？

M3 输出：

- 值得推进：进入 M5 的「形成当前世界观」。
- 观察：进入结果收口。
- 丢弃：进入结果收口，并注明「停止推进，不删除事实」。

M5 分成两条泳道。

「理解与决策」：

- 形成当前世界观：来源证据、冻结背景、当前世界、历史运行。
- 还原真实目标：明确完成标准。
- 深度调查：消息、会议、文档、代码、日志、实时状态。
- 决定下一步：不做、要做、暂停。

「行动与验证」：

- 拆解行动：目标、范围、边界、成功标准。
- 调度执行：执行子 Agent / 工具，只执行边界明确的任务。
- 收集结果与证据：产物、状态、异常、外部变化。
- 验证真实结果：是否达到完成标准？

关系必须准确：

- 「不做」进入结果收口。
- 「要做」先进入「拆解行动」，不得直达调度、收集或验证。
- 下层顺序固定为：拆解行动 → 调度执行 → 收集结果与证据 → 验证真实结果。
- 受控副作用需要审批时暂停。
- 「未通过：更新认知并重新规划」从「验证真实结果」返回「深度调查」。
- 「已通过」从验证进入结果收口。
- 不允许存在「决定下一步 → 验证真实结果」的捷径。

结果收口包括：

- 本轮结论：完成、观察 / 停止推进、等待 / 需要人工 / 待审批、失败。
- 总结与交付：对外结果、任务进展与 effects、完成依据与下一步。
- 结束或恢复：结束本轮；条件变化后从 M5 恢复。

世界模型包括：

- 实体与关系：Principal、人、项目、事项、资源。
- 当前认知：Summary，回答现在是什么。
- 时间证据：Fact，回答发生过什么。
- 行动状态：Todo、Task、执行结果。
- 维护语义：外部事实 + 执行结果 → 更新 Summary / Fact / 行动状态。

世界模型向 M3 提供「摘要读取」，与 M5 之间是「渐进读取 / 新认知维护」，结果收口后「验证后沉淀结果」。

## 视觉约束

- 暖灰白不透明背景。
- 主文字深蓝黑，普通连线浅灰。
- M5 使用工程蓝与极浅蓝底。
- M3 仅使用低饱和琥珀色区分。
- 依靠网格、留白、分区和细线建立层次。
- M5 占据最大面积；左侧紧凑，右侧收口稳定，世界模型低高度横贯底部。
- 禁止图标、人物、机器人、脑、数据库圆柱、旗帜。
- 禁止渐变、阴影、发光、玻璃拟态、3D、深色背景和彩虹配色。
- 禁止营销海报、仪表盘、PPT 模板和等宽卡片流水线风格。
- 禁止伪中文、随机英文、重复标题、未标注分支和交叉混乱的箭头。
