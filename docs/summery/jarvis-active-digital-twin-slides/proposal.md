# 主动式数字分身 Slides 内容方案

## 核心命题

Jarvis 不是等待提问的聊天机器人，而是一套持续维护现实状态、判断是否行动、把事情推进到底并校正自身认知的主动式数字分身。

## 最终结构

- 20 页，25–30 分钟。
- 能力与案例 8 页，核心问题与总架构 2 页，世界模型 4 页，决策执行 4 页，展望与收束 2 页。
- 世界模型只回答“保存什么、如何维护、如何进入判断”；决策章节只回答“谁在何时改变状态、怎样安全行动”。
- Todo / Task / ExecutionRun 在世界模型页作为结构骨架，在决策页作为状态流转，不重复定义。

## 20 页注册表

1. 主动式数字分身探索实践
2. 从 OpenClaw 到自建 Agent Loop
3. 它不是一个等人提问的机器人
4. 六类能力，围绕同一个人工作
5. 从问题到代码交付，一段对话闭环
6. 任务不必离开协作现场
7. 会议、Oncall、审批：都走同一套判断
8. 主动行为必须可观察、可介入、可追溯
9. 主动式真正难的，是分寸
10. Jarvis 内核只有两件事：状态与决策
11. 资料池会记住历史，世界模型要跟上现实
12. 一张图看懂整个世界模型
13. 核心方法不是检索，而是持续编译
14. 像人一样：先看目录，再按需详查
15. 快脑决定是否做，慢脑决定怎么做
16. 把资料扫描分出去，把裁决留在主脑
17. 提示词 + 工具，而不是为每个 Case 写代码
18. 审批不是流程阶段，而是模型随时可以选择的动作
19. 内核与领域无关，差距在全局调度
20. 正确地什么都不做

第 10、12、15 页是视觉与信息密度锚点，其余页面在同一设计系统内变化布局与节奏。
