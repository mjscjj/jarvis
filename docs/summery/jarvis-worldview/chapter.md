# 第一阶段：构建 Jarvis 可迭代的世界观

主动式 Agent 首先要解决的，不是“能调用多少工具”，而是“它眼中的世界是什么”。如果每次醒来都只看到眼前的一句话，它仍然只是响应式助手：不知道事情从哪里来、推进到哪里，也不知道自己刚刚做过什么。Jarvis 因此先建立一份可长期维护、持续修正，并能进入下一轮判断的世界模型。

> **主动式 Agent = 可迭代的世界观 + 自主决策 + 有边界的闭环执行**

## 1.0 什么是 Jarvis 的世界观

**世界模型，是 Jarvis 对现实世界的长期投影。** 它跨越单次对话和任务，保存相对稳定的对象、当前状态、历史变化和未闭环行动，回答“这个工作世界里有什么，现在分别怎样”。

**世界观，是 Agent 在具体时刻、围绕具体目标，从世界模型中构造出的认知切面。** 它不是另一份存储，而是带立场、时间和目标的理解：这件事为什么重要，和谁、哪个项目或承诺有关，现在最值得采取什么动作。同一份世界模型，可以按不同职责形成不同世界观。

Jarvis 的世界以 Principal 为坐标。它不建立关于整个组织的客观百科，而是从“我是谁、负责什么、什么对我重要”出发理解现实。Principal 不是与其他对象等权的普通节点；围绕这个坐标，Person、Project、Key Matter、Group、Resource 构成人、事、物和协作场的实体网络。

【图1：Jarvis 世界模型——以 Principal 为坐标的长期实体网络、认知记录与实时行动状态】

关系与时间贯穿网络，但不是额外实体。关系表达职责、归属、协作和依据；时间表达什么曾经成立、什么已经变化、什么仍在等待。它们把孤立对象组织成能够解释“为什么现在要行动”的上下文。

每个长期实体都有三类认知记录。Summary 回答“现在是什么”，保存当前最佳认知；Fact 回答“现实发生过什么”，保留带时间和来源的历史证据；PageRevision 保存旧版 Summary，记录认知怎样被改写。PageRevision 不是现实事实，不能冒充 Fact。

Todo、Task 和 ExecutionRun 属于实时行动状态，而不是长期实体。它们依次表示发现了什么、什么目标正在被承接，以及某次执行产生了什么结果。长期实体描述世界，行动状态描述世界里正在发生的工作。

## 1.1 Jarvis 怎么维护自己的世界观

世界模型不是一次录入完成的资料库，也不是不断追加信息。新消息、Todo 和 Task 的状态变化、执行结果与外部效果首先都只是增量证据。系统先定位受影响的人、项目、事项、群或资源，再结合已有 Summary 和 Fact 重新理解。

【图2：世界模型维护流程——现实变化成为增量证据，经比较、修正和留痕后形成新的当前认知】

一次维护通常有四种结果：重复或噪声不写；值得追溯但不改变现状，只追加 Fact；对象现状改变，追加 Fact 并改写 Summary；新证据与旧结论冲突，修正 Summary，并用 Fact 与 PageRevision 分别保留现实变化和认知变化。必要时也可建立新的长期实体。

重点不是“记得更多”，而是“让当前认知保持正确”。新证据应淘汰过期结论，同时保留改判依据；没有带来新认知时，什么都不写同样正确。

FactEngine 是主要维护者。它读取增量证据，维护长期实体、Summary 和 Fact，但不推进任务、不改变外部世界；它负责形成认知，而不是替 M5 执行。

世界模型也不是 FactEngine 的私有产物。M5 或主动巡视亲自核实到页面过时时，可以纠正已确认的部分，但不能把一次性过程写成长久事实。所有修改最终回到同一份世界模型，不制造平行真源。

## 1.2 世界观如何进入完整闭环

世界模型只有被下一轮判断读到，才不只是档案。Jarvis 采用“一份世界模型，多种按职责投影”：每个 Agent 只取当前职责需要的认知切面，并按需下钻。

【图3：完整闭环——感知 → 维护世界模型 → 构造目标相关世界观 → 自主决策 → 执行验证 → 结果回到证据】

M3 面对新线索，只取决定准入所需的最短证据；足以判断“执行、观察或忽略”后就停止，不提前完成 M5 的调查。

Proactive 面向开放事项、时间流逝和世界变化，寻找失速、重复、时机变化或新的机会；没有值得做的事时返回 NOTHING。需要改变外部世界时，它只创建普通 Task，把执行交给 M5。

M5 面对已经准入的目标，同时读取两类背景：M3 准入时冻结的完整快照，保留“当时为什么值得做”；本轮开始时的当前世界，反映最近哪些 Task 已完成、失败或仍在推进。实体最新状态从 Summary 读取，历史再沿 Fact 下钻。冻结背景和实时状态各有职责，不能互相替代。

在这个认知切面上，Agent 决定执行、调查、等待、询问 Principal，或者 NOTHING。执行后还要验证现实是否真的变化，区分“做了一个动作”和“目标已经达成”。成功、失败、等待和外部效果随后成为新证据，再次进入世界模型。

完整闭环因此是：感知现实变化，维护长期世界模型；围绕当前目标构造世界观；基于世界观自主决策；执行并验证真实结果；再把结果写回证据，让下一轮判断面对一个已经变化的世界。

这也解释了为什么它不只是 RAG：RAG 找回相关材料，Jarvis 维护的是随时间演化的对象、当前认知、行动状态，以及行动如何再次改变世界的因果闭环。
