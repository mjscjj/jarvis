# 主持会议

## 主持周报会议

1. 打开分享页，在页面最上方点击 **周报会议**，确认季度和周次。
2. 点击页面右上角 **评论**，再点击 **逐条浏览**。
3. 处理完当前评论后点击底部 **下一条**，继续下一条评论。
4. 评论需要形成后续待办时，点击评论上的 **标记 Todo**；已经完成讨论且无需跟进的评论可标记“已解决”。
5. 浏览完成后关闭评论抽屉，检查本周风险和 Todo，按需点击“导出全部 OKR”。

## 主持 Review + Plan 会议

会议统一按 **先 Review、后 Plan** 的顺序进行。

1. 在页面最上方点击 **Review 会议**，确认季度和 Review 周次。
2. 点击页面右上角 **评论**，打开评论抽屉。
3. 点击 **逐条浏览**，从第一条评论开始讨论。
4. 一条评论讨论结束后点击底部 **下一条**，继续处理下一条评论。
5. 如果评论需要形成后续待办，点击评论上的 **标记 Todo**；不需要跟进的评论可标记“已解决”。
6. 重复“讨论 → 标记 Todo / 解决 → 下一条”，直到页面提示评论已浏览完成。
7. Review 结束后，在页面最上方点击 **Biz OKR Plan**，切到下季度 Plan 继续讨论。
8. Plan 修改意见记录在对应原文评论中并 `@` 负责人，会后确认 Todo、负责人和页面保存状态。

## 完成标准

- 会议评论已经逐条处理。
- 需要后续推进的评论已点击“标记 Todo”。
- Review 完成后才进入 Plan，Plan 修改意见落在对应原文并有负责人。
