# 制定下季度 OKR Plan

## 什么时候使用

制定或讨论下季度业务目标、KR、衡量指标、策略具体 KR、产品具体 KR 及负责人。

## 基本填写

1. 打开分享页，在页面最上方点击 **Biz OKR Plan**，选择下季度并新建或选择 Plan。
2. 填写 O 和一级 KR，补充负责人、优先级、业务分类和成功标准。
3. 展开“指标与拆解”，分别增加策略具体 KR、产品具体 KR和核心数据。
4. 使用 AI 评审检查目标、成功标准和执行路径；用评论收集反馈。
5. 等待顶部显示保存成功。
6. 需要会外同步时，点击 AI 评审旁边的 **导出OKR Plan**。生成的飞书文档按业务方向分表，表格包含 O、KR、优先级、策略具体 KR、产品具体 KR，并合并相同 O 和 KR 的单元格。

## 怎么移动 KR

- 一级 KR 行右侧有 `↑`、`↓`：点击即可在**同一个 O 内**上移或下移。
- 到达第一条或最后一条时，对应按钮会置灰。
- 当前不支持把一级 KR 直接跨 O 拖动；需要跨 O 时，在目标 O 下新建 KR，确认内容后再删除原 KR。

## 怎么移动策略 / 产品具体 KR

- 每条具体 KR 行右侧有 `↑`、`↓`，用于在当前分组内排序。
- 要把“策略具体 KR”移动到“产品具体 KR”，使用具体 KR 标题左侧的分组下拉框，将类型从“策略”切换为“产品”；反向操作同理。
- 切换分组后，再用 `↑`、`↓` 调整它在新分组中的位置。

## 怎么删除 Plan 中的 KR

- **删除一级 KR：**在一级 KR 行右侧点击“删除”，阅读“只删除这个 Plan 草稿里的 KR”的提示，再点击“确认删除”。
- **删除策略 / 产品具体 KR：**把鼠标移到具体 KR 行，点击最右侧 `×`，再点击“确认”。
- 删除只作用于当前 Plan 草稿；删除前仍应确认没有其他协作者刚刚更新该条内容。

## 完成标准

- O 描述清晰的业务目标，KR 描述结果而不是任务清单。
- 重点 KR 有负责人、成功标准以及策略或产品拆解。
- 排序符合会议讨论顺序，页面已经显示保存成功。
