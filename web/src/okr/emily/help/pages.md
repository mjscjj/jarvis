# 页面介绍

分享页最上方固定展示以下五个 Tab。填写或主持会议时直接在这里切换，不需要返回 Emily 左侧菜单。

| 页面 | 什么时候使用 | 是否填写 | 主要能力 |
| --- | --- | --- | --- |
| Biz OKR Plan | 制定下季度 OKR、主持 Plan 讨论 | 是 | 编辑 O / KR、策略与产品拆解、负责人、排序、评论、AI 评审和飞书文档导出 |
| Review 填写 | Review 会前由负责人填写结果和复盘 | 是 | 填结果、归因、评分、文档、图片和 AI 评审 |
| Review 会议 | 主持阶段或季度 Review | 部分可编辑 | 查看复盘、调整评分和 Todo、评论、导出 |
| 周报填写 | 每周由负责人更新进展 | 是 | 核心数据、本周进展、完成状态和评论 |
| 周报会议 | 主持每周周报会 | 以查看为主 | 投屏浏览、按负责人筛选、评论和导出 |

## 快速判断

- 我要更新本周进展 → **周报填写**
- 我要开本周周报会 → **周报会议**
- 我要填写阶段复盘 → **Review 填写**
- 我要主持 Review → **Review 会议**
- 我要制定或讨论下季度目标 → **Biz OKR Plan**
