# 高频问题

## 怎么查看跟我相关的评论？

有两种查看方式：

1. **集中查看：**在当前 Plan、周报或 Review 页面点击右上角“评论”，再点击顶部的“与我相关”。这里会显示别人 `@` 你的评论、你创建或回复过的讨论，以及别人对这些讨论的回复。
2. **按负责范围检查：**在页面“负责人”筛选中选择自己的姓名，再逐项查看自己负责的 OKR 是否有评论。

建议在自己实际负责的 OKR 上把“负责人”设置为自己，避免按姓名筛选时漏掉相关 OKR。打开评论后，点击“评论原文”可回到内容所在位置。

## 怎么粘贴文档和图片？

**文档：**把鼠标移到一条进展上，点击“+ 链接”，粘贴飞书文档、知识库或 Meego 链接；标题可以留空，Emily 会自动识别。

**图片：**点击核心数据或进展所在区域，再按 `⌘V` / `Ctrl+V` 粘贴截图。评论区也可以点击“添加图片”或直接粘贴，单条评论最多 9 张。

## 怎么删除 Plan 页面的 KR、产品具体 KR或策略具体 KR？

**一级 KR：**在 KR 行右侧点击“删除”，确认提示为“只删除这个 Plan 草稿里的 KR”，再点击“确认删除”。

**产品 / 策略具体 KR：**把鼠标移到具体 KR 行，点击最右侧 `×`，再点击“确认”。两类具体 KR 的删除方式相同。删除前请确认没有其他协作者刚刚更新该条内容。
