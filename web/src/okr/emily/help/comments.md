# 查看与我相关的评论

## 什么时候使用

集中查看别人 `@` 我的评论、我创建或回复过的讨论；也可以按负责人筛选自己，逐项检查自己负责的 OKR 是否有评论。

## 方式一：从评论抽屉集中查看

1. 在当前 Plan、周报或 Review 页面点击右上角“评论”。
2. 点击评论抽屉顶部的 **与我相关**。
3. 点击“评论原文”回到对应 O、KR、具体 KR、进展或选中文字。
4. 回复时如果要提醒对方，输入 `@` 并从人员选择器中选择；只输入姓名不会发送提醒。
5. 需要继续推进时标记为 Todo；处理完成后标记“已解决”。
6. 已解决内容默认隐藏，需要回看时点击“显示历史评论”。

## 方式二：按负责人检查自己负责的 OKR

1. 在 Plan、周报或 Review 页面找到“负责人”筛选。
2. 选择自己的姓名，只保留自己负责的 O、KR 和具体 KR。
3. 逐项查看评论入口及评论数量，打开有评论的 OKR 处理讨论。
4. 点击“评论原文”可返回对应内容；回复时按需 `@` 对方，并将需继续推进的内容标记为 Todo。

> 建议：在自己实际负责的 OKR 上，把“负责人”设置为自己。这样按姓名筛选时不会漏掉相关 OKR 和它下面的评论。

## 什么算“与我相关”

- 评论或回复明确 `@` 我；
- 我创建的评论；
- 我回复过的讨论串；
- 别人回复了我参与过的讨论串。

## 完成标准

- 需要本人回复的讨论已经处理。
- 需要后续推进的事项已标记 Todo，而不是只在正文里写“待办”。
- 已结束的讨论已标记解决。
- 按负责人筛选时，自己实际负责的 OKR 没有因负责人缺失或填写错误而被漏掉。
